## 🌟 What is FocusMode?

FocusMode is a premium, state-of-the-art web application specifically tailored for students preparing for highly competitive exams like JEE, NEET, and UPSC. By blending proven productivity methods with modern gamification and real-time social connectivity, FocusMode dramatically boosts student engagement and study endurance.

**Ready for market launch and commercial scaling**, FocusMode offers an incredibly polished user experience with micro-animations, glassmorphism UI, and lightning-fast PWA offline capabilities.

## 🏆 Key Selling Features

- 🎮 **Gamified Learning Experience**: Keep users addicted to studying! Built-in XP tracking, level-ups, and daily study streaks turn exam prep into a rewarding game. 
- 💬 **Real-time "Squad" Chat & Community**: Powered by Firebase Realtime Database. Students connect, collaborate, and compete with online peers. The chat features robust moderation, profanity filters, and real-time PWA auto-sync.
- ⏳ **Advanced Pomodoro & Task Tracking**: Smart session managers designed around real-life study patterns.
- 📱 **Progressive Web App (PWA)**: Works offline! Installs directly to iOS and Android devices natively. Features auto-updating service workers to push instantaneous live updates to users globally without requiring app store updates.
- 🎨 **Premium Aesthetic**: Crafted with bespoke UI/UX principles. Stunning gradients, responsive layouts, glassmorphic panels, and butter-smooth CSS animations.

## 💻 Tech Stack

- **Frontend**: React 18 + Vite (Lightning fast builds & HMR)
- **Styling**: Pure CSS3 with modern CSS Variables (No bloat, highly performant UI)
- **Backend/Realtime**: Firebase Realtime DB & Server-Sent Events (SSE)
- **Offline & Cache**: Vite PWA with advanced Workbox window strategies

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
